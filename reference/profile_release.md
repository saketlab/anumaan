# Final Per-Group Release Table

Combines
[`profile_define_cohort`](https://saketlab.github.io/anumaan/reference/profile_define_cohort.md)'s
pre-fit support tier with every post-fit check this family produces –
[`profile_check_sampler`](https://saketlab.github.io/anumaan/reference/profile_check_sampler.md),
[`profile_ppc`](https://saketlab.github.io/anumaan/reference/profile_ppc.md),
[`profile_validate_masked`](https://saketlab.github.io/anumaan/reference/profile_validate_masked.md)/[`profile_validate_heldout`](https://saketlab.github.io/anumaan/reference/profile_validate_heldout.md),
[`profile_sensitivity`](https://saketlab.github.io/anumaan/reference/profile_sensitivity.md)
– into one per-group table, WITHOUT collapsing any of them into a single
trust label. Every post-fit argument is optional and independently
`NULL`-able: a check that was not run is reported as
`NA`/`"not_evaluated"`, never silently omitted or inferred.

## Usage

``` r
profile_release(
  cohort_manifest,
  sampler_check = NULL,
  ppc = NULL,
  heldout = NULL,
  sensitivity = NULL,
  manual_judgment = NULL,
  output_dir = NULL
)
```

## Arguments

- cohort_manifest:

  Data frame. The `$manifest` element of
  [`profile_define_cohort`](https://saketlab.github.io/anumaan/reference/profile_define_cohort.md)'s
  return value (needs `group`, `included`, `reason`).

- sampler_check:

  List or `NULL`. Return value of
  [`profile_check_sampler`](https://saketlab.github.io/anumaan/reference/profile_check_sampler.md)
  (one verdict for the whole fit, repeated on every row – a sampler
  either worked or it didn't, regardless of group).

- ppc:

  List or `NULL`. Return value of
  [`profile_ppc`](https://saketlab.github.io/anumaan/reference/profile_ppc.md)
  (`$marginal`/`$pairwise`/`$complete_profile`).

- heldout:

  List or `NULL`. Return value of
  [`profile_validate_masked`](https://saketlab.github.io/anumaan/reference/profile_validate_masked.md)
  or
  [`profile_validate_heldout`](https://saketlab.github.io/anumaan/reference/profile_validate_heldout.md)
  (reads `$predictions`).

- sensitivity:

  Data frame or `NULL`. Return value of
  [`profile_sensitivity`](https://saketlab.github.io/anumaan/reference/profile_sensitivity.md).

- manual_judgment:

  Named list (`group -> reason`), data frame (`group`, `reason`
  columns), or `NULL`. Analyst judgment, recorded verbatim with its
  stated reason – never generated by this function.

- output_dir:

  Character or `NULL`. If supplied, writes the returned table as
  `release_table.csv` and `.rds`.

## Value

A data frame, one row per group appearing in ANY of the supplied inputs
(a group the cohort manifest excluded but that still shows up in, say,
`ppc` is not dropped): `group`, `initial_included`,
`initial_tier_reason`, `sampler_status`, `sampler_reasons`,
`ppc_status`, `ppc_flagged_checks`, `heldout_n_masked`,
`heldout_accuracy`, `heldout_brier`, `heldout_auroc`,
`max_sensitivity_contrast`, `manual_judgment_reason`.

## Details

`manual_judgment`, if supplied, is recorded as its own column with its
own reason text – it never overwrites `initial_tier_reason`,
`sampler_status`, `ppc_status`, or any other field computed from actual
evidence above it.
