# Complete-profile statistics, split by measurement unit (Phase A does the minimum split needed so the axis is never labelled "Value" across incompatible units; a fuller redesign – worst-deviation labelling, rare-vs-common profile zoom – is a later phase). Group A (0-1 scale: frequencies + Simpson concentration) is faceted by hospital; group B (profile count) and group C (entropy) are compact dotplots, since there is only one statistic each per hospital, not a hospital x metric grid.
